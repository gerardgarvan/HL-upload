<task type="auto">
  <name>Task 2: Create setup verification script</name>
  <files>scripts/verify_setup.sh</files>
  <action>
Create scripts/verify_setup.sh - a bash script collaborators run after completing environment setup to verify everything is configured correctly before attempting the pipeline. This replaces/updates the existing scripts/setup_hpc.sh which was an older setup script focused on initial installation rather than verification.

The script should:

1. Start with `#!/bin/bash` and `set -euo pipefail`
2. Add a header comment: "Setup verification for HL Data Pipeline. Run after completing docs/SETUP.md environment and configuration steps. Verifies conda env, Python, dependencies, config, and compute node."
3. Define color helpers (GREEN, RED, YELLOW, NC) and ok/fail/warn functions (can reuse pattern from setup_hpc.sh)
4. Print a header banner: "HL Data Pipeline - Setup Verification"

Run these checks in order:

**Check 1: Conda environment**
- Verify $CONDA_DEFAULT_ENV equals "hl-eda"
- If not, print: "hl-eda environment not activated. Run: conda activate hl-eda"
- Exit 1 on failure

**Check 2: Python version**
- Run `python --version` and check output contains "3.11" or "3.12" or "3.13" or "3.14"
- Print the version on success
- Exit 1 if unexpected version

**Check 3: Core dependencies importable**
- Run `python -c "import polars, pandas, pyarrow, pytest, jinja2, tabulate"`
- On success: print "Core dependencies importable"
- On failure: print "Import failed - run: conda env create -f environment.yml"
- Exit 1 on failure

**Check 4: Config validation**
- Run `python -c "from src.load.config import load_and_validate_config; load_and_validate_config()"`
- On success: print "Configuration validated (config/paths.toml)"
- On failure: print "Config validation failed - check config/paths.toml paths"
- Exit 1 on failure

**Check 5: Compute node warning**
- Check if hostname contains "login"
- If yes: print warning "Currently on login node - use 'srun --pty --mem=16gb --time=2:00:00 bash' for pipeline execution"
- If no: print "On compute node: $(hostname)"

**Check 6: Source data accessible**
- Run `python -c "from src.load.config import load_config; p = load_config(); print(p.data_root)"` to get data_root
- Check if the directory exists with `[ -d "$DATA_ROOT" ]`
- On success: print "Source data accessible: $DATA_ROOT"
- On failure: print warning "Source data not accessible (expected if on login node without /orange mount)"

Print summary at end: "Setup verification complete - N/N checks passed"

Make the script executable (note: Claude should mention chmod +x in the action but the Write tool handles content only, so add a note that execute-plan should run chmod +x).

NOTE: Do NOT modify or remove scripts/setup_hpc.sh. It serves a different purpose (initial HPC installation). The new verify_setup.sh is for post-setup verification.
  </action>

  </verify>
