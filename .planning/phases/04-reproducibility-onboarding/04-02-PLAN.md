**Section 7: Troubleshooting**

Common issues and solutions:

1. **"conda: command not found" after conda init** - Logout and login required after `conda init bash`
2. **"ModuleNotFoundError: No module named 'polars'"** - Environment not activated. Run `conda activate hl-eda`
3. **"FileNotFoundError" during pipeline** - Check config/paths.toml paths. Run the config validation command.
4. **Process killed during pipeline** - Running on login node. Use `srun` for compute node.
5. **"module load conda" fails** - Try `module avail conda` to find exact module name on current HyperGator
6. **Slow conda env create** - Use mamba: `mamba env create -f environment.yml` (install mamba with `conda install -n base mamba`)
7. **Permission denied on /orange or /blue** - Contact PI or HyperGator support for filesystem access
8. **Golden baseline shows differences** - May be due to different library versions. Generate lock file: `conda env export --no-builds > environment_lock.yml` and compare with original author's lock file
