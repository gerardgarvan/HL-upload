Create `scripts/build_insurance_presentation.py` that reads Phase 5 and Phase 6 CSV outputs and generates a UF-branded PowerPoint presentation.

**Script setup** — follow existing project pattern:
- MODULE docstring explaining purpose, inputs, outputs, and usage
- `PROJECT_ROOT = Path(__file__).resolve().parents[1]` and `sys.path.insert(0, str(PROJECT_ROOT))`
- Import `polars as pl`, `from pptx import Presentation`, `from pptx.util import Inches, Pt`, `from pptx.dml.color import RGBColor`, `from pptx.enum.text import MSO_ANCHOR, PP_ALIGN`
- Import `from src.load.config import load_and_validate_config`
- Accept optional config_path from sys.argv[1]

**Constants:**
- `UF_BLUE = RGBColor.from_string("003087")`
- `UF_ORANGE = RGBColor.from_string("FA4616")`
- `WHITE = RGBColor(255, 255, 255)`
- `LIGHT_BLUE = RGBColor(0xCC, 0xD5, 0xEA)` — light blue tint for odd data rows
- `LIGHT_ORANGE = RGBColor(0xFD, 0xD9, 0xCC)` — light orange tint for even data rows
- `DARK_TEXT = RGBColor(0x33, 0x33, 0x33)` — near-black for body text
- `PAYER_CATEGORY_ORDER` — 9 categories: Medicare, Medicaid, Dual eligible, Private, Other government, Self-pay, Other, Unavailable, Unknown

**CSV file mapping** — define as a data structure:

Phase 5 CSVs (reports/insurance_by_treatment/):
- `overview_table.csv` — columns include `Payer Category`, `Primary Insurance (N_Pct)`, and two more `(N_Pct)` columns whose labels vary (could be `First Diagnosis (N_Pct)` or `Primary Insurance (N_Pct)`)
- `chemotherapy_table.csv` — columns: `Payer Category`, `Primary Insurance (N_Pct)`, `First Chemo (N_Pct)`, `Last Chemo (N_Pct)`
- `radiation_table.csv` — columns: `Payer Category`, `Primary Insurance (N_Pct)`, `First Radiation (N_Pct)`, `Last Radiation (N_Pct)`
- `sct_table.csv` — columns: `Payer Category`, `Primary Insurance (N_Pct)`, `First SCT (N_Pct)`, `Last SCT (N_Pct)`

Phase 6 CSVs (reports/post_treatment_insurance/):
- `combined_post_treatment.csv` — columns: `Payer Category`, `Post-Treatment Insurance (N_Pct)` — has 10 rows (9 payer + N/A row)
- `chemo_post_treatment.csv` — columns: `Payer Category`, `Post-Treatment Insurance (N_Pct)` — 9 rows
- `radiation_post_treatment.csv` — same structure — 9 rows
- `sct_post_treatment.csv` — same structure — 9 rows

**Reading CSVs:**
- Read all 8 CSVs with `pl.read_csv()`, wrapping each in try/except for graceful error handling (warn and skip if a CSV is missing)
- For Phase 5 CSVs: detect the N_Pct column names dynamically (filter column names ending in `(N_Pct)`) since the overview table has variable column headers
- Extract cohort size from each CSV by summing the `(N)` column values for the first data column (e.g., `Primary Insurance (N)`)
- For the title slide: total N from overview, chemo N from chemotherapy_table, radiation N from radiation_table, SCT N from sct_table

**Presentation setup:**
- `prs = Presentation()`
- `prs.slide_width = Inches(10)` and `prs.slide_height = Inches(5.625)` for 16:9 aspect ratio

**Slide 1 — Title slide:**
- Use `prs.slide_layouts[6]` (blank layout) — do NOT use layout[0] as it has unpredictable placeholders
- Add a text box for title: "Insurance Coverage by Treatment Type" at `Inches(0.5), Inches(1.2), Inches(9.0), Inches(1.0)`, font size Pt(28), bold, color UF_BLUE
- Add subtitle text box: "Hodgkin Lymphoma Cohort — UF Health" at `Inches(0.5), Inches(2.2), Inches(9.0), Inches(0.5)`, font size Pt(16), color DARK_TEXT
- Add cohort sizes text box at `Inches(0.5), Inches(3.0), Inches(9.0), Inches(1.5)` listing:
  - `Total Cohort: N = {total_n:,}`
  - `Chemotherapy: N = {chemo_n:,}`
  - `Radiation: N = {radiation_n:,}`
  - `Stem Cell Transplant: N = {sct_n:,}`
  Font size Pt(14), color DARK_TEXT. Use `add_paragraph()` for each line after the first.
- Add a colored accent bar: a thin rectangle shape `Inches(0.5), Inches(2.0), Inches(4.0), Inches(0.04)` filled with UF_ORANGE to separate title from subtitle

**Helper: `_add_table_slide(prs, title, subtitle, df, n_pct_columns, payer_col="Payer Category")`:**
- `prs.slide_layouts[6]` (blank layout)
- Title text box at `Inches(0.5), Inches(0.2), Inches(9.0), Inches(0.5)`, font Pt(22), bold, UF_BLUE
- Subtitle text box at `Inches(0.5), Inches(0.65), Inches(9.0), Inches(0.3)`, font Pt(12), italic, DARK_TEXT
- Table positioned at `left=Inches(0.5), top=Inches(1.1), width=Inches(9.0), height=Inches(4.0)`
- Number of rows = number of data rows + 1 (header)
- Number of cols = 1 (Payer Category) + len(n_pct_columns)
- **Header row formatting:**
  - Each header cell: fill.solid(), fill.fore_color.rgb = UF_BLUE
  - Text: white, bold, Pt(11), centered horizontally (PP_ALIGN.CENTER), vertically (MSO_ANCHOR.MIDDLE)
  - First header cell text: "Payer Category"
  - Remaining header texts: clean column names by removing " (N_Pct)" suffix
- **Data row formatting:**
  - Alternate row colors: odd rows (0-indexed from data start) get LIGHT_BLUE, even rows get LIGHT_ORANGE
  - First column (payer category name): left-aligned, bold, Pt(10), DARK_TEXT
  - Data columns: center-aligned, Pt(10), DARK_TEXT
  - All cells: vertical_anchor = MSO_ANCHOR.MIDDLE
  - Cell margins: margin_left=Inches(0.08), margin_right=Inches(0.08), margin_top=Inches(0.04), margin_bottom=Inches(0.04)
- **Column widths:**
  - First column (Payer Category): set to Inches(2.2)
  - Remaining columns: distribute remaining width equally: `(9.0 - 2.2) / len(n_pct_columns)` inches each

**Slide order (per CONTEXT.md locked decisions):**

- Data: overview_table.csv, show all N_Pct columns

Slide 4: Chemotherapy Insurance (Phase 5)
- Title: "Chemotherapy Insurance"

- Data: chemotherapy_table.csv

- Title: "Chemotherapy Post-Treatment Insurance"

Slide 6: Radiation Insurance (Phase 5)

- Subtitle: "Insurance at primary, first, and last radiation — N = {radiation_n:,}"
- Data: radiation_table.csv

Slide 8: SCT Insurance (Phase 5)
