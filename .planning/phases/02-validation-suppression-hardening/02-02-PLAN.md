  <name>Task 1: Create centralized suppression module</name>
  <files>

  <action>
Create `src/report/suppression.py` with:

1. Module docstring with clinical rationale:
   - HIPAA Safe Harbor method requires suppressing small cell counts to prevent re-identification
   - Threshold of 10 per CMS Cell Suppression Policy and WA DOH standards
   - Primary suppression only (no complementary) per user decision
   - References: CMS Cell Size Suppression Policy, WA DOH Small Numbers Standards

2. `DEFAULT_THRESHOLD = 10` — single constant, single source of truth.

3. `def suppress(value: int, threshold: int = DEFAULT_THRESHOLD) -> str`:
   - If value == 0: return "0" (zero is safe per user decision — reveals no individual)
   - If 1 <= value <= threshold: return "-"
   - Else: return str(value)
   - Google-style docstring with examples

4. `def flag_small_cell(value: int, threshold: int = DEFAULT_THRESHOLD) -> str`:
   - If 1 <= value <= threshold: return f"{value} [!]"
   - Else: return str(value)
   - Note: Uses "[!]" marker (matching existing codebase pattern from structural.py)
   - Check existing structural.py for exact marker format and match it

5. `def audit_suppression(counts: list[int], threshold: int = DEFAULT_THRESHOLD) -> dict`:
   - Returns dict with: total_cells, suppressed_cells, zero_cells, pct_suppressed
   - Useful for logging suppression impact during report generation
   - Example: `{"total_cells": 50, "suppressed_cells": 3, "zero_cells": 5, "pct_suppressed": 6.0}`

6. For backward compatibility, also export `_suppress = suppress` as an alias so any remaining references to `_suppress` work during migration.

Important: Check the EXACT marker format in `src/validate/structural.py` flag_small_cell() and match it. The research doc shows "[!]" but the codebase may use a different symbol.
  </action>
