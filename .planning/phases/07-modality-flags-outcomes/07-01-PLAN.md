  <action>
Add to outcomes_flags.py:

1. **add_modality_flags(patient_df: pl.DataFrame, table_map: dict[str, Path], outcomes_path: Path)** → pl.DataFrame
   - Load lookup: lookup = load_outcomes_code_lookup(outcomes_path)
   - Get HL patient IDs from patient_df (PATID_COL)
   - For each modality:
     - cpt_hcpcs: pl.scan_parquet(PROCEDURES).filter(pl.col(PATID_COL).is_in(ids)).filter(pl.col("PX").is_in(codes)).select(PATID_COL).unique()
     - loinc: pl.scan_parquet(LAB_RESULT_CM).filter(pl.col(PATID_COL).is_in(ids)).filter(pl.col("LAB_LOINC").is_in(codes)).select(PATID_COL).unique()
     - icd10: pl.scan_parquet(DIAGNOSIS).filter(pl.col(PATID_COL).is_in(ids)).filter(pl.col("DX").is_in(codes)).select(PATID_COL).unique()
   - Normalize PX and DX for matching: PROCEDURES.PX and DIAGNOSIS.DX may have dots (e.g. C81.10) or not. Use .str.to_uppercase().str.replace_all(".", "") for DX; PX/LAB_LOINC typically no dots — match codes as-is (Outcomes codes have no dots for CPT/HCPCS/LOINC)
   - Merge: patients with ≥1 match in any of cpt_hcpcs, loinc, icd10 get flag=1
   - Add column MODALITY_{slug} = 1 or 0 (Int8)
   - Left-join flags to patient_df on PATID_COL (patients not in any match get 0)
   - Import PATID_COL from src.validate.structural
2. PROCEDURES: PX_TYPE may indicate CPT (09) vs HCPCS (HC); both stored in PX. Match PX against combined cpt_hcpcs set.
3. DIAGNOSIS: DX may be dotted (C81.10) or undotted. Outcomes ICD-10-PCS codes (e.g. 30230C0) have no dots. Use normalized match: strip dots from DX, uppercase; compare against uppercase code set.
4. LAB_RESULT_CM: LAB_LOINC — exact match, case-normalize if needed (LOINC codes are often numeric with hyphen)
