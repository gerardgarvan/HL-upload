   - Both flags: Int8, 0/1; use pl.when().then().otherwise()

   - Fill null PROVIDER_SPECIALTY_PRIMARY with ""
   - Pattern = "|".join(ONCOLOGY_KEYWORDS); case-insensitive str.contains
   - FLAG_CANCER_PROVIDER = 1 if match else 0 (Int8)
