Create the core post-treatment insurance analysis script that computes mode payer category from encounters after each patient's last treatment date and outputs 4 summary tables as CSV + markdown.

This extends the Phase 5 treatment-stratified analysis with a post-treatment perspective.

Create a new script `scripts/build_post_treatment_insurance.py` that reads encounter_payer_summary.parquet and clean/ENCOUNTER.parquet, computes post-treatment payer mode, and generates 4 summary tables.

**Module structure (follow build_insurance_by_treatment.py pattern):**
- Module docstring explaining purpose (Phase 6: post-treatment insurance tables)
- sys.path setup for PROJECT_ROOT (same pattern as Phase 5 script)
- Import polars, pathlib, datetime, html
- Import from src.load.config: load_and_validate_config

- Import from src.validate.structural: PATID_COL
- Define PAYER_CATEGORY_ORDER (same 9 categories as Phase 5 script, using "Self-pay" not "No payment / Self-pay")

**Post-treatment payer computation function `_compute_post_treatment_payer()`:**

1. Read encounter_payer_summary.parquet (patient-level, has LAST_CHEMO_DATE, LAST_RADIATION_DATE, LAST_SCT_DATE, HAD_CHEMO, HAD_RADIATION, HAD_SCT columns)
2. Compute LAST_TREATMENT_DATE per patient using `pl.max_horizontal("LAST_CHEMO_DATE", "LAST_RADIATION_DATE", "LAST_SCT_DATE")` — this ignores nulls automatically, returns null only if ALL three are null
3. Compute HAD_ANY_TREATMENT flag: `(HAD_CHEMO==1) | (HAD_RADIATION==1) | (HAD_SCT==1)`
4. Read clean/ENCOUNTER.parquet to get raw encounters with ADMIT_DATE and PAYER_TYPE_PRIMARY (and PAYER_TYPE_SECONDARY if present)
5. Join encounters to patients on PATID, filter to ADMIT_DATE > LAST_TREATMENT_DATE (strict greater-than, per user decision "immediately after")
6. Apply effective payer logic from encounter_payer_summary.py: use _effective_payer_and_dual_exprs() to get effective_payer and dual_eligible expressions, then _payer_category_from_effective_and_dual() to get payer category per encounter
7. Compute mode (most frequent) payer category per patient across their post-treatment encounters (same pattern as _payer_mode_in_window: group_by PATID+PAYER_CATEGORY, count, sort descending, group_by PATID, first)
8. Left join mode results back to all patients. Patients with no post-treatment encounters get null mode -> fill with "Unknown" per user decision
9. For combined table: patients with HAD_ANY_TREATMENT==0 get POST_TREATMENT_PAYER = "N/A (No Treatment)"
10. Return DataFrame with PATID, POST_TREATMENT_PAYER, HAD_CHEMO, HAD_RADIATION, HAD_SCT, HAD_ANY_TREATMENT

**Table building function `_build_post_treatment_table()`:**
- Parameters: df (filtered cohort DataFrame), col_name (POST_TREATMENT_PAYER), cohort_label, include_na_row (bool, True only for combined table)
- Count patients by POST_TREATMENT_PAYER category
- Build rows in PAYER_CATEGORY_ORDER (9 rows)
- If include_na_row=True: append "N/A (No Treatment)" row at bottom (10th row)
- Each row: {"Payer Category": cat, "Post-Treatment Insurance (N)": n, "Post-Treatment Insurance (%)": pct, "Post-Treatment Insurance (N_Pct)": "N (X.X%)"}
- Return (rows, cohort_size) tuple

**main() function:**
1. Load config with load_and_validate_config()
2. Read encounter_payer_summary.parquet from derived_dir; exit 0 if missing
3. Check required date columns exist (LAST_CHEMO_DATE, LAST_RADIATION_DATE, LAST_SCT_DATE) with graceful degradation (warn but continue if some missing — last_treatment_date still computed from available columns)
4. Check required treatment flag columns exist (HAD_CHEMO, HAD_RADIATION, HAD_SCT)
5. Call _compute_post_treatment_payer() to get patient-level post-treatment payer
6. Build 4 tables:
   - Combined: ALL patients (had treatment -> mode payer, no treatment -> "N/A (No Treatment)"), include_na_row=True
   - Chemo cohort: filter HAD_CHEMO==1, include_na_row=False
   - Radiation cohort: filter HAD_RADIATION==1, include_na_row=False
   - SCT cohort: filter HAD_SCT==1, include_na_row=False
7. Write CSV for each table to reports/post_treatment_insurance/
8. Write combined markdown README with all 4 tables and methodology section

**CSV output files:**

**Critical edge cases (from CONTEXT.md decisions):**
- Patients with LAST_TREATMENT_DATE but no encounters after it -> POST_TREATMENT_PAYER = "Unknown"
- Patients with HAD_ANY_TREATMENT==0 (no chemo, no radiation, no SCT) -> POST_TREATMENT_PAYER = "N/A (No Treatment)" in combined table only
- Per-cohort tables use Phase 5 cohort definitions: HAD_CHEMO==1 (not HAD_CHEMO==1 AND LAST_CHEMO_DATE not null)

- "Self-pay" label (matching Phase 5), NOT "No payment / Self-pay" from encounter_payer_summary.py. Map "No payment / Self-pay" -> "Self-pay" when categorizing.
