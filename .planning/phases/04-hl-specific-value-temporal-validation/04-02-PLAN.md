**Helper: _build_table_map** — duplicate from validate_all.py (6 lines; same logic: stem.split("_Mailhot_V1")[0] → parquet path).

**Helper: _load_birth_death_lookup(table_map) -> tuple[pl.DataFrame, pl.DataFrame]:**
- Load DEMOGRAPHIC: select ID, BIRTH_DATE. Cast ID to String.
- Load DEATH (if exists): select ID, DEATH_DATE. Cast ID to String.
- **Masked birth date recovery:** For patients where BIRTH_DATE == MASKED_BIRTH_DATE (1900-01-01), attempt to recover an approximate birth year from TUMOR_REGISTRY. If any TUMOR_REGISTRY table exists in table_map, load ID, AGE_AT_DIAGNOSIS, DATE_OF_DIAGNOSIS. For masked patients, compute approximate birth date as `DATE_OF_DIAGNOSIS - AGE_AT_DIAGNOSIS years` (approximate: use Jan 1 of the computed year). Update birth_df for those patients so they get temporal checks instead of being skipped entirely.
- Return (birth_df, death_df). Used for cross-table temporal checks.

**Helper: _validate_against_birth(df: pl.DataFrame, birth_df: pl.DataFrame, date_cols: list[str]) -> pl.DataFrame:**
- Join df with birth_df on ID (left join).
- For each date column in date_cols: create `{col}_val_before_birth` = 1 when:
  - BIRTH_DATE is not null AND BIRTH_DATE != MASKED_BIRTH_DATE (1900-01-01)
  - AND date column is not null
  - AND date column < BIRTH_DATE
- Drop the joined BIRTH_DATE column before returning.
- Return df with flag columns.

**Helper: _validate_against_death(df: pl.DataFrame, death_df: pl.DataFrame, date_cols: list[str]) -> pl.DataFrame:**
- Join df with death_df on ID (left join).
- For each date column in date_cols: create `{col}_val_after_death` = 1 when:
  - DEATH_DATE is not null AND date column is not null AND date column > DEATH_DATE
- Drop the joined DEATH_DATE column before returning.
- Return df with flag columns.

**Helper: _get_date_columns(df: pl.DataFrame) -> list[str]:**
- Return list of column names where dtype is pl.Date or pl.Datetime.
- Exclude columns that already have "_val_" in name.

**Helper: _compute_hl_timeline(table_map: dict, reports_dir: Path) -> dict:**
- This computes the HL disease timeline summary (cross-table, NOT per-row flags — per research/CONTEXT decision).
- Load DIAGNOSIS parquet. Filter to HL codes (use ALL_HL_CODES or ALL_HL_NORMALIZED from cohort.py based on format detection — import detect_dx_format, ALL_HL_CODES, ALL_HL_NORMALIZED from cohort.py).
- Per patient (ID): find earliest DX_DATE as FIRST_HL_DX_DATE.
- Load PROCEDURES parquet. Filter to HL-relevant CPT codes from OUTCOMES_FEASIBILITY (stem cell transplant CPT codes, plus radiation CPT codes if available). Per patient: find earliest PX_DATE as FIRST_TX_DATE_PX.
- Load PRESCRIBING parquet (if exists). Per patient: find earliest RX_ORDER_DATE as FIRST_TX_DATE_RX.
- Optionally check TUMOR_REGISTRY for treatment dates (DT_SURG, DT_RAD, DT_CHEMO — probe columns at runtime).
- Per patient: FIRST_TX_DATE = min across all sources. DX_TO_TX_DAYS = FIRST_TX_DATE - FIRST_HL_DX_DATE.
- Flag patients where DX_TO_TX_DAYS < 0 (treatment before DX) or DX_TO_TX_DAYS > 365 (per user decision: 0-365 days expected).
- Return summary dict: {total_patients, with_treatment, median_dx_to_tx, flagged_before_dx, flagged_over_365, distribution_buckets}.

**main(config_path: Path | None = None) -> None:**

Print header: "HL DATA LOADING & CLEANING — VALUE & TEMPORAL VALIDATION"

1. Load config, parse table filenames, build table_map.
2. Build value set lookup from paths.valuesets_path.
3. Load birth/death lookup.
4. Detect ICD-mapped partners (load DIAGNOSIS, call detect_mapped_partners).
5. Initialize report_data dict and concordance_data dict.

6. **Main validation loop** — for each (table_name, pq_path) in sorted table_map:
   - Print progress: `[N/total] table_name`
   - Skip if parquet not found.
   - Read parquet: `df = pl.read_parquet(pq_path)`
   - Drop existing flags: `df = drop_existing_flags(df)`
   - Apply value set validation: `df = validate_coded_fields(df, table_name, lookup)` — skip for TUMOR_REGISTRY tables (NAACCR, not CDM value sets).
   - Apply table-specific checks:
     - VITAL: `df = validate_vital_plausibility(df)`
     - LAB_RESULT_CM: `df = validate_lab_plausibility(df)`
     - DIAGNOSIS: `df = validate_icd_concordance(df, mapped_partners)`. Save concordance stats for CSV.
     - ENCOUNTER: `df = validate_temporal_encounter(df)`
     - ENROLLMENT: `df = validate_enrollment_dates(df)`
     - TUMOR_REGISTRY*: `df = validate_tumor_registry(df)`
   - Apply universal temporal checks:
     - `df = validate_future_dates(df)`
     - If table has date columns AND table is not DEMOGRAPHIC or DEATH: apply birth/death temporal checks using _validate_against_birth and _validate_against_death.
   - Write back: `stats = write_validated(df, pq_path)`
   - Store stats in report_data[table_name].
   - Print summary: flags added, rows flagged.

7. **Cross-table HL timeline** — call _compute_hl_timeline(table_map, reports_dir). Store results.

8. **ICD concordance CSV** — compute per-partner breakdown from DIAGNOSIS data:
   - Reload DIAGNOSIS (or use cached data). Group by SOURCE (partner).
   - Per partner: count total DX, ICD-9 count, ICD-10 count, pre-transition ICD-10 count, flagged count, whether partner is mapped.
   - Write to reports/icd_concordance.csv using polars write_csv.

9. **Generate reports** — call report functions (Task 2).

10. Print summary: tables validated, total flags, elapsed time, report file paths.

**__main__ block:** Same pattern as validate_all.py — try/except with sys.exit.

**Function: _section_overview(report_data: dict) -> str:**
- Generate "## 1. Validation Overview" section.
- Table: | Table | Rows | Flag Columns | Rows With Any Flag | for each table in report_data.
- Compute "rows with any flag" = rows where at least one _val_ column == 1 (this info should be in report_data from write_validated stats).
- Apply flag_small_cell to counts.

**Function: _section_valueset(report_data: dict) -> str:**
- Generate "## 2. Value Set Conformance" section.
- For each table, list coded fields checked and their flag rates.
- Highlight fields with >5% flag rate.
- Skip tables with no _val_code flags.
- Apply flag_small_cell.

**Function: _section_plausibility(report_data: dict) -> str:**
- Generate "## 3. Plausibility Checks" section.
- Subsections for Vital Signs and Lab Results.
- Vital signs: table showing | Measure | Range | Flagged | % | per measure.
- Lab results: table showing | Lab | LOINC | Range | Unit | Flagged | % | per LOINC code.
- Include RESULT_UNIT_val_missing count.
- Apply flag_small_cell.

**Function: _section_icd_concordance(concordance_data: dict) -> str:**
- Generate "## 4. ICD Version-Date Concordance" section.
- Summary: total DX records, total flagged, flag rate.
- Per-partner table: | Partner | Total DX | ICD-9 | ICD-10 | Flagged | Mapped? |
- Note about grace period (Jul 2015 – Jan 2016) and auto-detected mapped partners.
- Apply flag_small_cell.

**Function: _section_temporal(report_data: dict, hl_timeline: dict) -> str:**
- Generate "## 5. Temporal Consistency" section.
- Subsections:
  - Encounter: admit/discharge violations, same-day encounter count (stratify same-day by ENC_TYPE if available — note in text that outpatient same-day is expected).
  - Future dates: count per table.
  - Before-birth / after-death flag counts per table.
  - Enrollment: ENR_START > ENR_END violations.
  - HL Disease Timeline: summary stats from _compute_hl_timeline result — median days DX→TX, patients with treatment before DX, patients with gap >365 days. This is summary-only, not per-row flags.
- Apply flag_small_cell.

**Function: _section_tumor_registry(report_data: dict) -> str:**
- Generate "## 6. Tumor Registry Validation" section.
- Only show if any TUMOR_REGISTRY tables were validated.
- Table: | Check | Field | Valid | Invalid | % Invalid | per check type (histology, stage, B-symptoms, age, treatment timing, primary site).
- Note that only ORL, TMH, UFH have TR data.
- Apply flag_small_cell.

**Function: _write_temporal_issues_csv(report_data: dict, hl_timeline: dict, reports_dir: Path):**
- Write reports/temporal_issues.csv with columns: table, check_type, flagged_count, total_rows, flag_rate.
- Include rows for: admit_discharge, same_day, future_date (per table), before_birth (per table), after_death (per table), enr_dates, hl_timeline_before_dx, hl_timeline_over_365.
- Apply small-cell suppression: if flagged_count in 1-10, replace with "-".

**Function: _write_tumor_registry_csv(report_data: dict, reports_dir: Path):**
- Write reports/tumor_registry_validation.csv with columns: table, check, field, valid_count, invalid_count, invalid_pct.
- One row per check per TR table.
- Apply small-cell suppression.
