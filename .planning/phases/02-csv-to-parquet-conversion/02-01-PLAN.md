Create `src/load/convert.py` with the following functions. Use Polars exclusively (no pandas). All code patterns are validated by Phase 2 research (02-RESEARCH.md).

**Constants and imports:**
- `import polars as pl`, `import re`, `import csv`, `from datetime import date`, `from pathlib import Path`, `import time`
- `KNOWN_DATE_COLS`: set of known PCORnet CDM + NAACCR date column names. Include all of: `BIRTH_DATE`, `ADMIT_DATE`, `DISCHARGE_DATE`, `DX_DATE`, `PX_DATE`, `MEASURE_DATE`, `SPECIMEN_DATE`, `RESULT_DATE`, `RX_ORDER_DATE`, `RX_START_DATE`, `RX_END_DATE`, `DEATH_DATE`, `ONSET_DATE`, `REPORT_DATE`, `RESOLVE_DATE`, `DISPENSE_DATE`, `ENR_START_DATE`, `ENR_END_DATE`, `MEDADMIN_START_DATE`, `MEDADMIN_STOP_DATE`, `VX_RECORD_DATE`, `VX_ADMIN_DATE`, `VX_EXP_DATE`, `ADDRESS_PERIOD_START`, `ADDRESS_PERIOD_END`, `DATE_OF_BIRTH`, `DATE_OF_DIAGNOSIS`
- `DATE_NAME_RE`: regex pattern matching `(_DATE|_DT)$|^DATE_|^DT_|_DATE_` (case-insensitive) — catches date-like column names not in the known set
- `DATE9_RE`: `r"^\d{2}[A-Za-z]{3}\d{4}$"` — matches "01JAN2020"
- `DATETIME_RE`: `r"^\d{2}[A-Za-z]{3}\d{4}:\d{2}:\d{2}:\d{2}$"` — matches "01JAN2020:14:30:00"
- `YYYYMMDD_RE`: `r"^\d{8}$"` — matches "20200101"
- `MIN_DATE = date(1900, 1, 1)`, `MAX_DATE = date(2026, 12, 31)`

**`detect_date_columns(df: pl.DataFrame, sample_size: int = 200) -> dict[str, str]`:**
Auto-detect date columns using two-phase approach (per user locked decision: auto-detect by sampling, not just hardcoded lists):
1. Phase A — name heuristic: check if column is in KNOWN_DATE_COLS or matches DATE_NAME_RE
2. Phase B — value sampling: for each String column, sample up to `sample_size` non-null, non-empty values. Count matches against DATETIME_RE (check first — it's a superset of DATE9.), DATE9_RE, and YYYYMMDD_RE
3. Use lower match threshold (30%) when name also matches; higher threshold (50%) for value-only detection
4. YYYYMMDD only accepted if name heuristic ALSO matches (avoids false positives on 8-digit codes like SITE_CODE or HISTOLOGY — per research pitfall #3)
5. Handle mixed formats: if name matches and combined format matches exceed threshold, pick the dominant format
6. Skip non-String columns (all should be String due to `infer_schema=False`, but be defensive)
7. Return `{column_name: format_string}` dict

**`convert_date_column(df: pl.DataFrame, col: str, fmt: str) -> tuple[pl.DataFrame, dict]`:**
Convert a single string column to date/datetime with 10% threshold (per user locked decision):
1. Count original non-null, non-empty values as denominator
2. If denominator is 0, return unchanged df with stats `{"action": "skipped", "reason": "all null/empty"}`
3. Record original null count
4. If format contains `:%H:%M:%S`: use `pl.col(col).str.to_datetime(fmt, strict=False)` — this is for SAS DATETIME format. Per user locked decision, date and time columns are kept separate (PCORnet CDM structure), so only apply datetime parsing to columns that actually have time components
5. Otherwise: use `pl.col(col).str.to_date(fmt, strict=False)`
6. Compute `new_nulls = converted_null_count - original_null_count`
7. If `new_nulls / denominator > 0.10`: return ORIGINAL df (keep as string) with stats `{"action": "kept_as_string", "reason": "...% failed to parse", "failures": new_nulls}`
8. Otherwise: return converted df with stats `{"action": "converted", "format": fmt, "new_nulls": new_nulls}`

Per user locked decision: do NOT keep raw string copies — replace in-place with typed version only. Chrono's `%b` parser is case-insensitive (verified in research), so no `.str.to_uppercase()` needed.

**`validate_date_range(df: pl.DataFrame, col: str) -> dict`:**
Validate converted date/datetime column against [1900-01-01, 2026-12-31] range (per user locked decision: very permissive, only flag obviously wrong values):
1. If column dtype is `pl.Date`: filter for non-null values where `col < MIN_DATE` or `col > MAX_DATE`, count them
2. If column dtype is `pl.Datetime`: cast to date first for comparison, same filter
3. Compute min and max values
4. Return `{"col": col, "min": str(min_val), "max": str(max_val), "out_of_range": count}`
5. This is informational only — flag but preserve all values (masked BIRTH_DATE="01JAN1900" → 1900-01-01 is valid data, not an error)

**`convert_table(csv_path: Path, parquet_dir: Path) -> dict`:**
Orchestrate single-table conversion. Returns an inventory record dict.
1. Record start time
2. Get csv_bytes from `csv_path.stat().st_size`
3. Derive `table_name` from filename: strip `_Mailhot_V1.csv` suffix (e.g., `DEMOGRAPHIC_Mailhot_V1.csv` → `DEMOGRAPHIC`)
4. Read CSV: `pl.read_csv(csv_path, infer_schema=False, encoding="utf8-lossy")` — `infer_schema=False` prevents Polars auto-inferring date columns as integers (research pitfall #1); `encoding="utf8-lossy"` handles non-UTF-8 characters (research pitfall #5)
5. If `df.height == 0`: per user locked decision, skip empty tables — return inventory record with `status="empty"`, do NOT create a Parquet file. Print a notice.
6. Store `csv_rows = df.height`
7. Call `detect_date_columns(df)` to get `{col: fmt}` dict
8. For each detected date column: call `convert_date_column(df, col, fmt)`, update df, accumulate stats. Then call `validate_date_range` on successfully converted columns and print range info.
9. Derive parquet filename: same as CSV but `.parquet` extension (per user locked decision: keep cohort suffix, e.g., `DEMOGRAPHIC_Mailhot_V1.parquet`)
10. Write: `df.write_parquet(parquet_dir / parquet_filename, compression="snappy")` — snappy per user locked decision
11. Read back: `pl.read_parquet(parquet_path)` and get `parquet_rows`
12. If `csv_rows != parquet_rows`: per user locked decision, warn but continue (log the discrepancy)
13. Get `parquet_bytes` from stat
14. Record elapsed time
15. Return inventory dict with fields: `table_name`, `csv_file`, `parquet_file`, `csv_rows`, `parquet_rows`, `csv_bytes`, `parquet_bytes`, `date_columns_found` (count), `date_columns_converted` (count), `date_columns_kept_string` (count), `elapsed_seconds`, `status`

**`write_inventory(records: list[dict], output_path: Path) -> None`:**
Write `file_inventory.csv` using Python csv module. Fields: `table_name`, `csv_file`, `parquet_file`, `csv_rows`, `parquet_rows`, `csv_bytes`, `parquet_bytes`, `date_columns_found`, `date_columns_converted`, `date_columns_kept_string`, `elapsed_seconds`, `status`.
