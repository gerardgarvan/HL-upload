    - Small-cell flagging logic
    </details>

    - Cross-table consistency checks

    - Flag columns added per table
    - Consistency check descriptions
    </details>

    **Module:** src/report/quality_report.py

    - Write quality reports: DATA_QUALITY_REPORT.md, CLEANING_DECISIONS.md

    ### Data Transformations
    - Aggregation: encounter-level → patient-level (many rows per patient → one)

    - Demographics: BIRTH_DATE, SEX, RACE, ETHNICITY
    - HL: subtype, first DX date, first DX code
    - Treatment: HAD_CHEMO, HAD_RADIATION, HAD_SCT
    - Payer: effective payer, dual-eligible flag
    </details>

    ## Phase 5: Insurance/Payer Analysis
    **Script:** scripts/build_insurance_summary.py
    **Module:** src/report/encounter_payer_summary.py

    - Output: CSV tables, markdown summary, PNG figures
    - Small-cell suppression applied to all published counts

    - Dual-eligible detection codes
    - 30-day treatment window logic
    - Category mapping (PCORnet codes → reporting categories)
    </details>

    - Applied to: all published reports (CSV, markdown)
    - Parquet files retain actual counts for re-analysis

    - config/paths.toml: data_root, scratch_root, parquet_dir, derived_dir
