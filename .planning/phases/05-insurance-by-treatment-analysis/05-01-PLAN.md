Create `scripts/build_insurance_by_treatment.py` that replaces `build_insurance_summary.py`. This task builds the data foundation; Plan 02 adds PNG and HTML rendering on top.

**Script structure:**

1. **Imports and constants:**
   - Import polars, pathlib, sys, csv
   - Import `load_and_validate_config` from `src.load.config` (same pattern as existing script)
   - Set PROJECT_ROOT = Path(__file__).resolve().parents[1] and sys.path.insert(0, str(PROJECT_ROOT))
   - Define PAYER_CATEGORY_ORDER list: Medicare, Medicaid, Dual eligible, Private, Other government, Self-pay, Other, Unavailable, Unknown (9 categories)
   - Do NOT import suppress or flag_small_cell — no HIPAA suppression per user decision

2. **Column validation at startup:**
   - Define REQUIRED_COLUMNS dict mapping treatment type to required column names:
     - "chemo": ["HAD_CHEMO", "PAYER_CATEGORY_PRIMARY", "PAYER_CATEGORY_AT_FIRST_CHEMO", "PAYER_CATEGORY_AT_LAST_CHEMO"]
     - "radiation": ["HAD_RADIATION", "PAYER_CATEGORY_PRIMARY", "PAYER_CATEGORY_AT_FIRST_RADIATION", "PAYER_CATEGORY_AT_LAST_RADIATION"]
     - "sct": ["HAD_SCT", "PAYER_CATEGORY_PRIMARY", "PAYER_CATEGORY_AT_FIRST_SCT", "PAYER_CATEGORY_AT_LAST_SCT"]
   - On startup, check which treatment column sets are present. Print clear messages for missing columns: "Required columns missing for {treatment}. Re-run: python scripts/assemble_clean.py"
   - Continue with available treatments (don't crash if only some treatments have columns)
   - Exit with code 1 only if ALL treatment columns are missing

3. **Aggregation helper function `_build_table(df, primary_col, first_col, last_col, cohort_label)`:**
   - Takes filtered cohort DataFrame and column names
   - For each of the 9 payer categories in PAYER_CATEGORY_ORDER:
     - Count N for primary_col matching that category (normalize nulls/empty to "Unknown")
     - Count N for first_col matching that category
     - Count N for last_col matching that category
     - Compute percentage: 100.0 * N / cohort_size
     - Format cell as f"{N} ({pct:.1f}%)" — NO suppression
   - If a payer category has 0 patients, show "0 (0.0%)"
   - Return a list of dicts: [{"Payer Category": ..., "Primary Insurance": ..., "First Treatment": ..., "Last Treatment": ...}, ...]
   - Also return cohort_size (int) for header

4. **Main function:**
   - Load config, read parquet, validate columns (as above)
   - Create output directory: `reports/insurance_by_treatment/` (relative to PROJECT_ROOT)
   - Build 4 tables:
     - **Chemotherapy:** Filter HAD_CHEMO==1, use PAYER_CATEGORY_PRIMARY, PAYER_CATEGORY_AT_FIRST_CHEMO, PAYER_CATEGORY_AT_LAST_CHEMO
     - **Radiation:** Filter HAD_RADIATION==1, use PAYER_CATEGORY_PRIMARY, PAYER_CATEGORY_AT_FIRST_RADIATION, PAYER_CATEGORY_AT_LAST_RADIATION
     - **SCT:** Filter HAD_SCT==1, use PAYER_CATEGORY_PRIMARY, PAYER_CATEGORY_AT_FIRST_SCT, PAYER_CATEGORY_AT_LAST_SCT
     - **Overview:** No filter (all enrolled patients), use PAYER_CATEGORY_PRIMARY for all 3 columns (Primary = mode across encounters, First = PAYER_CATEGORY_AT_FIRST_DX if available, Last = PAYER_CATEGORY_PRIMARY). If PAYER_CATEGORY_AT_FIRST_DX is not in columns, use PAYER_CATEGORY_PRIMARY for first column too, and note in header.
   - Write CSV for each table (4 files): chemotherapy_table.csv, radiation_table.csv, sct_table.csv, overview_table.csv
   - Write combined markdown README.md with all 4 tables, each with header "## {Treatment} Cohort (N={size})"

5. **Key design decisions:**
   - Self-pay category: Use "Self-pay" (not "No payment / Self-pay" from old script) per CONTEXT.md payer category list
   - Normalize: Replace nulls and empty strings with "Unknown" before aggregation (reuse pattern from existing script)
   - No total row, no total column per user decision
   - CSV includes raw N and Pct columns alongside formatted N_Pct for downstream use

6. **`if __name__ == "__main__"` block:** Accept optional config path argument (same pattern as existing script).
