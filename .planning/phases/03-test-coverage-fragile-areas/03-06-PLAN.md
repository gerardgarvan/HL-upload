<task type="auto">
  <name>Create pytest.ini configuration</name>
  <files>pytest.ini</files>
  <action>
Create pytest configuration file for test discovery, reporting, and coverage settings.

**Create pytest.ini in repository root:**

```ini
[pytest]
# Test discovery
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*

# Output settings
addopts =
    -v
    --strict-markers
    --tb=short
    --color=yes

# Markers for organizing tests
markers =
    payer: tests for payer logic (TEST-01)
    dates: tests for date parsing (TEST-02)
    reports: tests for report generation (TEST-03)
    checkpoint: tests for checkpoint validation (TEST-04)
    audit: tests resolving TODO(audit) items
    slow: marks tests as slow (deselect with '-m "not slow"')

# Warnings
filterwarnings =
    error
    ignore::DeprecationWarning
    ignore::PendingDeprecationWarning

# Coverage settings (optional, requires pytest-cov)
# Uncomment if pytest-cov installed:
# addopts = --cov=src --cov-report=term-missing --cov-report=html
```

**Rationale for settings:**
- `testpaths = tests`: Only search tests/ directory (not src/ or scripts/)
- `-v`: Verbose output showing test names
- `--strict-markers`: Fail if unregistered markers used
- `--tb=short`: Shorter traceback format for readability
- Markers: Organize tests by requirement (TEST-01 through TEST-04) for selective execution

**Add pytest markers to tests:**
In each test file, add marker decorators:
```python
@pytest.mark.payer
def test_collapse_payer_category_all_pcornet_codes():
    ...

@pytest.mark.dates
def test_detect_date_columns_format_detection():
    ...

@pytest.mark.reports
def test_suppress_boundary_values():
    ...

@pytest.mark.checkpoint
def test_validate_row_count_exact_match_pass():
    ...
```

**This enables selective test execution:**
```bash
pytest -m payer         # Run only payer logic tests (TEST-01)
pytest -m dates         # Run only date parsing tests (TEST-02)
pytest -m "not slow"    # Skip slow tests
```
