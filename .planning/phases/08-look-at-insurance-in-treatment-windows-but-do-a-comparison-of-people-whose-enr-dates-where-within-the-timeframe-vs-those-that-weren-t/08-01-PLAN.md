<objective>
Build the Phase 8 enrollment comparison analysis script that:
1. Checks whether each patient's ENROLLMENT periods fully cover the +/-30 day treatment window
2. Produces side-by-side comparison tables (ENR Covers vs Does Not Cover) for DX, Chemo, Radiation, SCT
3. Produces Unknown post-treatment payer diagnostic breakdown by encounter count
4. Outputs all tables in CSV, PNG, HTML, and markdown formats

Purpose: Reveal whether payer classifications at treatment are backed by enrollment records (reliable) or potentially missing data (unreliable), and diagnose why some patients have "Unknown" post-treatment payer.

Output: `scripts/build_insurance_enr_comparison.py` + `reports/insurance_enr_comparison/` directory with CSV, PNG, HTML, and markdown for all 5 tables.
</objective>

**3. `_check_enrollment_covers_window(patient_id, window_start, window_end, enrollment_df)` -> bool** (per D-04/D-05/D-06):
- Filter enrollment_df to patient's records (ID == patient_id), sort by ENR_START_DATE
- If empty: return False (D-06)
- Initialize `covered_until = window_start - timedelta(days=1)`
- Walk through sorted enrollment periods:
  - Skip rows with null ENR_START_DATE or ENR_END_DATE
  - If start > covered_until + timedelta(days=1): gap detected, return False
  - Extend: `covered_until = max(covered_until, end)`
  - If covered_until >= window_end: return True
- After loop: return `covered_until >= window_end`

**4. `_flag_enrollment_coverage(patients_df, enrollment_df, date_col, window_days=30)` -> pl.DataFrame**:
- Takes patients DataFrame with ID and date_col columns
- For each patient, compute window_start = date_col - 30 days, window_end = date_col + 30 days (per D-03)
- Call _check_enrollment_covers_window per patient
- Return DataFrame with ID and ENR_COVERS_WINDOW column (Int8: 1/0)
- Use iter_rows for correctness (Python loop), not vectorized (per RESEARCH.md recommendation)

**5. `_normalize_payer_with_na(series)` -> pl.Series**:
- Null -> "N/A" (NOT "Unknown" — per D-11, distinguishing null payer from Unknown category)
- "No payment / Self-pay" -> "Self-pay"
- Otherwise keep as-is

**6. `_build_comparison_table(df, payer_col, enr_flag_col)` -> tuple[list[dict], int, int]**:
- Split df by enr_flag_col == 1 (covered) vs == 0 (not covered)

- Normalize payer column using _normalize_payer_with_na
- Count payer categories in each group
- Build rows for each of PAYER_CATEGORY_ORDER + ["N/A"] (10 rows per D-12/D-11)

- Return (rows, n_covered, n_not_covered)
