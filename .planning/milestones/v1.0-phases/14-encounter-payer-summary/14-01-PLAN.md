  <action>
Create src/report/encounter_payer_summary.py.

1. **build_encounter_payer_summary(table_map: dict[str, Path]) -> pl.DataFrame**
   - Load ENCOUNTER from table_map["ENCOUNTER"]; return empty DataFrame with schema if not found
   - PATID_COL = "ID"; cast ID to String
   - Define valid payer: PAYER_TYPE_PRIMARY not null, not empty, not in {"NI","UN","OT"}
   - Aggregate by ID:
     - N_ENCOUNTERS: pl.len()
     - N_ENCOUNTERS_WITH_PAYER: count where valid payer (filter before agg or use pl.when)
     - N_DISTINCT_PAYERS: n_unique of PAYER_TYPE_PRIMARY where valid (use filter + distinct count per patient)
     - PAYER_PRIMARY: mode (most frequent PAYER_TYPE_PRIMARY among valid); use group_by + value_counts or first on sorted by count
     - PAYER_TRANSITION: 1 if N_DISTINCT_PAYERS > 1 else 0 (Int8)
   - PAYER_PRIMARY: filter rows where valid payer, group_by ID, agg mode. Polars: pl.col("PAYER_TYPE_PRIMARY").mode().first() or count + sort + first
   - Schema: ID (String), N_ENCOUNTERS (Int64), N_ENCOUNTERS_WITH_PAYER (Int64), N_DISTINCT_PAYERS (Int64), PAYER_PRIMARY (String), PAYER_TRANSITION (Int8)

2. **Valid payer filter (reuse site_table pattern):**
   pl.col("PAYER_TYPE_PRIMARY").is_not_null() & (pl.col("PAYER_TYPE_PRIMARY") != "") & ~pl.col("PAYER_TYPE_PRIMARY").is_in(["NI","UN","OT"])

3. **PAYER_PRIMARY logic:** For each patient, from rows with valid payer, take the PAYER_TYPE_PRIMARY value with highest count. Use group_by + value_counts + sort + first, or filter valid then group_by + mode.

4. Import from src.validate.structural: PATID_COL
