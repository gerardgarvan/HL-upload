**Utility function:**

`_ensure_float(df: pl.DataFrame, col: str) -> pl.DataFrame`:
- Check if df schema shows col as pl.String (or pl.Utf8). If so, cast to pl.Float64 with strict=False.
- Return df. Handles the Pitfall 1 from research (numeric columns may be String after Phase 2).

**Function 1: build_valueset_lookup(valuesets_path: Path) -> dict[tuple[str, str], set[str]]**
- Read valuesets.csv with `pl.read_csv(valuesets_path)`.
- Group rows by (TABLE_NAME, FIELD_NAME) → set of VALUESET_ITEM values.
- Return the lookup dict. Efficient: iterate once, build dict of sets.

**Function 2: validate_coded_fields(df: pl.DataFrame, table_name: str, lookup: dict[tuple[str, str], set[str]]) -> pl.DataFrame**
- For each column in df.columns, check if (table_name, column) exists in lookup.
- If yes, build valid set = lookup[(table_name, column)] | ALWAYS_VALID_CODES.
- Create flag column `{COLUMN}_val_code` = 1 when value is NOT null AND NOT empty AND NOT in valid set. Use `pl.when(pl.col(col).is_null() | (pl.col(col) == "") | pl.col(col).is_in(valid)).then(0).otherwise(1).cast(pl.Int8)`.
- Skip columns with >200 valid values in the value set (avoid false positives on loosely-coded fields per Pitfall 2 from research).
- Return df with flag columns added.

**Function 3: validate_vital_plausibility(df: pl.DataFrame) -> pl.DataFrame**
- For each (col, (lo, hi)) in VITAL_RANGES, skip if col not in df.columns.
- Call _ensure_float(df, col) first.
- Create flag `{col}_val_range` = 1 when value is NOT null AND (value < lo OR value > hi).
- Return df.

**Function 4: validate_lab_plausibility(df: pl.DataFrame) -> pl.DataFrame**
- Guard: if LAB_LOINC or RESULT_NUM not in df.columns, return df unchanged.
- Call _ensure_float(df, "RESULT_NUM").
- Flag missing RESULT_UNIT: create `RESULT_UNIT_val_missing` = 1 when RESULT_NUM is not null AND RESULT_UNIT is null or empty. Per user locked decision, missing unit is flagged separately.
- For range checks: build a chained `pl.when().then().otherwise()` expression across all LOINC codes in HL_LAB_RANGES. For each LOINC code, flag when LAB_LOINC matches AND RESULT_NUM is not null AND (RESULT_NUM < min OR RESULT_NUM > max). Produce single column `RESULT_NUM_val_range`.
- Return df.

**Function 5: detect_mapped_partners(df: pl.DataFrame, partner_col: str = "SOURCE") -> set[str]**
- Guard: if partner_col or DX_DATE not in df.columns, return {"AMS", "UMI"} (known mappers).
- Filter to pre-Oct-2015 records (DX_DATE < ICD10_TRANSITION).
- Per partner: compute fraction of codes starting with a letter (ICD-10 pattern) using `pl.col("DX").str.to_uppercase().str.contains(r"^[A-Z]")`.
- Partners with >95% ICD-10 codes in pre-transition data = mapped.
- Union with {"AMS", "UMI"} (always included per user decision).
- Return set of mapped partner names.

**Function 6: validate_icd_concordance(df: pl.DataFrame, mapped_partners: set[str], partner_col: str = "SOURCE") -> pl.DataFrame**
- Guard: if DX or DX_DATE not in df.columns, return df unchanged.
- Detect ICD version: `is_icd10 = pl.col("DX").str.to_uppercase().str.contains(r"^[A-Z]")`.
- Define grace period: `in_grace = DX_DATE >= GRACE_START AND DX_DATE < GRACE_END`.
- Define mapped: `is_mapped = pl.col(partner_col).is_in(mapped_partners)` if partner_col in df.columns, else `pl.lit(False)`.
- Flag logic (DX_val_icd_concordance):
  - Null DX_DATE → 0
  - In grace period → 0
  - ICD-9 code AND DX_DATE >= GRACE_END → 1 (ICD-9 used after transition)
  - ICD-10 code AND DX_DATE < GRACE_START AND NOT mapped → 1 (ICD-10 used before transition)
  - Otherwise → 0
- Cast to Int8. Return df with flag column.

**Function 7: validate_temporal_encounter(df: pl.DataFrame) -> pl.DataFrame**
- Guard: if ADMIT_DATE or DISCHARGE_DATE not in df.columns, return df.
- `_val_admit_discharge` = 1 when both dates non-null AND DISCHARGE_DATE < ADMIT_DATE.
- `_val_same_day` = 1 when both dates non-null AND ADMIT_DATE == DISCHARGE_DATE. Per user locked decision: always flag same-day.
- Return df.

**Function 8: validate_future_dates(df: pl.DataFrame, cutoff: date | None = None) -> pl.DataFrame**
- Use FUTURE_DATE_CUTOFF if cutoff is None.
- For each column in df where dtype is Date or Datetime: create `{col}_val_future` = 1 when value > cutoff.
- Return df. Handles all tables uniformly.

**Function 9: validate_enrollment_dates(df: pl.DataFrame) -> pl.DataFrame**
- Guard: if ENR_START_DATE or ENR_END_DATE not in df.columns, return df.
- `_val_enr_dates` = 1 when both non-null AND ENR_START_DATE > ENR_END_DATE.
- Return df.

**Function 10: validate_tumor_registry(df: pl.DataFrame) -> pl.DataFrame**
- HL histology: if HISTOLOGY in df.columns, _ensure_float then cast to Int64 (strict=False). `HISTOLOGY_val_hl` = 1 when non-null AND value not in HL_HISTOLOGY_CODES (9650–9667).
- AJCC staging: if STAGE_GROUP in df.columns, `STAGE_GROUP_val_format` = 1 when non-null AND not empty AND not in VALID_AJCC_STAGES (case-insensitive check: `.str.to_uppercase().is_in(...)`).
- B-symptoms: probe for column B_SYMPTOMS first, then CS_SSF1 if B_SYMPTOMS absent (per research Pitfall 3). If found, flag as `{col}_val_code` = 1 when non-null AND not empty AND not in {"A", "B", "1", "2", "9", "8", ""} (NAACCR B-symptom codes — 1=A/absent, 2=B/present, 9=unknown, 8=N/A).
- AGE_AT_DIAGNOSIS: if present, _ensure_float. `AGE_AT_DIAGNOSIS_val_range` = 1 when non-null AND value not in 0–120 range AND value != 200 (masked sentinel).
- Treatment timing: if DATE_OF_DIAGNOSIS in columns, check each treatment date column (probe for DT_SURG, DT_RAD, DT_CHEMO, CHEMO_START_DATE_SUMMARY, MOST_DEFINITIVE_SURGERY_DATE, IMMUNO_START_DATE, HORMONE_START_DATE). For each found: `{tx_col}_val_before_dx` = 1 when both non-null AND treatment date < DATE_OF_DIAGNOSIS.
- PRIMARY_SITE: if present, `PRIMARY_SITE_val_hl` = 1 when non-null AND not in C770–C779 + C778 range (check string pattern `^C77[0-9]$`). Note: this flags non-lymph-node primary sites which is expected for some HL presentations, so this is informational.
- Return df.

**Function 11: drop_existing_flags(df: pl.DataFrame) -> pl.DataFrame**
- Identify columns containing "_val_" in the name.
- If any found, drop them.
- Return df. Enables idempotent re-runs per user decision.

**Function 12: write_validated(df: pl.DataFrame, parquet_path: Path) -> dict**
- Count flag columns (those with "_val_" in name).
- For each flag column, compute sum (count of 1s).
- Write df to parquet_path with compression="zstd" (match Phase 2 convention — actually check: Phase 2 used snappy. Use "snappy" for consistency).
- Return stats dict: {"path": str(parquet_path), "total_rows": df.height, "flag_columns_added": N, "flags": {flag_name: count}}.

**File structure:** Follow existing codebase conventions — top-level constants, then functions grouped by domain, each with a docstring. Use `# ---------------------------------------------------------------------------` section dividers matching structural.py and cohort.py style.
