Create `src/validate/structural.py` with the following constants and functions. Use `import polars as pl` — no other external dependencies.

**Constants:**
- `PATID_COL = "ID"` — patient identifier column name in this dataset (NOT "PATID")
- `SMALL_CELL_THRESHOLD = 10`
- `ENCOUNTER_LINKED_TABLES` — list of tables that should have ENCOUNTERID: DIAGNOSIS, PROCEDURES, CONDITION, VITAL, LAB_RESULT_CM, PRESCRIBING, MED_ADMIN, OBS_CLIN, OBS_GEN, IMMUNIZATION
- `PATID_LINKED_TABLES` — list of all non-DEMOGRAPHIC tables that should have ID: ENROLLMENT, ENCOUNTER, DIAGNOSIS, PROCEDURES, CONDITION, VITAL, LAB_RESULT_CM, PRESCRIBING, DISPENSING, MED_ADMIN, DEATH, DEATH_CAUSE, LDS_ADDRESS_HISTORY, IMMUNIZATION, OBS_CLIN, OBS_GEN, PRO_CM, TUMOR_REGISTRY1, TUMOR_REGISTRY2, TUMOR_REGISTRY3
- `TUMOR_REGISTRY_TABLES` — set: TUMOR_REGISTRY1, TUMOR_REGISTRY2, TUMOR_REGISTRY3
- `TUMOR_REGISTRY_EXPECTED_COUNTS` — dict: TUMOR_REGISTRY1→265, TUMOR_REGISTRY2→120, TUMOR_REGISTRY3→120
- `TUMOR_REGISTRY_KEY_VARS` — set of key variables to verify in TR: ID, DATE_OF_DIAGNOSIS, HISTOLOGY, PRIMARY_SITE, STAGE_GROUP, AGE_AT_DIAGNOSIS (adapt to actual column names at runtime)

**Functions:**

1. `parse_cover_page(path: Path) -> dict[str, list[str]]`:
   Parse the DatasetCoverPage text file at `path` to extract expected column names per CDM table. Read with `encoding="utf-8-sig"` to handle BOM. The file format is unknown until runtime — probe adaptively:
   - Read all lines, look for lines containing known table names (DEMOGRAPHIC, ENCOUNTER, DIAGNOSIS, etc.) as section markers
   - Try tab-delimited parsing first: table sections may be separated by lines with table names, followed by rows of variable names
   - Collect column/variable names from each section
   - Return `{table_name: [column_names]}`
   - If format is completely unrecognizable, return empty dict and print a warning (don't crash)

2. `validate_table_schema(parquet_path: Path, expected_cols: list[str] | None, table_name: str, is_tumor_registry: bool = False, expected_col_count: int | None = None) -> dict`:
   Compare Parquet schema via `pl.read_parquet_schema(parquet_path)` against expected columns.
   - For TUMOR_REGISTRY tables: only check column count (warn if >10 difference from expected) and verify key variables are present. Don't validate against CDM spec.
   - For CDM tables: compute extra columns (actual - expected) and missing columns (expected - actual). Extra = warn and keep. Missing = warn only.
   - Return dict with table, actual_col_count, expected_col_count, matched, extra, missing, status, details.

3. `check_patid_uniqueness(demographic_path: Path) -> dict`:
   Verify ID is unique in DEMOGRAPHIC using `pl.scan_parquet()`. Return total_rows, unique_ids, duplicate_ids, is_unique.

4. `check_patid_integrity(child_path: Path, demographic_path: Path, child_table: str) -> dict`:
   Anti-join to find orphan IDs. Cast ID to `pl.String` on both sides before joining (prevents type mismatch errors — Phase 2 read CSVs as all-strings but types may vary). Return unique_ids, orphan_ids, orphan_pct.

5. `check_encounterid_integrity(child_path: Path, encounter_path: Path, child_table: str, skip_partner: str | None = None, partner_col: str = "SOURCE") -> dict`:
   Anti-join for orphan ENCOUNTERIDs. If `skip_partner` is set (e.g. "CHP" for LAB_RESULT_CM), filter out that partner's records before checking. If ENCOUNTERID column doesn't exist in the child table schema, return skipped=True. Filter null ENCOUNTERIDs before the anti-join. Return unique_encounterids, orphan_encounterids, orphan_pct, skip_partner.

6. `completeness_by_partner(parquet_path: Path, table_name: str, partner_col: str = "SOURCE") -> pl.DataFrame`:
   Compute per-column completeness (1 - null_count/len) grouped by SOURCE. If SOURCE column doesn't exist, try "SITE" as fallback; if neither exists, skip partner stratification and compute overall completeness. Use `pl.scan_parquet()` for lazy evaluation. Unpivot to long form with columns: [partner_col, row_count, column, completeness, table].

7. `classify_missing_values(parquet_path: Path, table_name: str, partner_col: str = "SOURCE") -> pl.DataFrame`:
   For string columns, count occurrences of PCORnet missing value codes: "NI" (no information), "UN" (unknown), "OT" (other), empty string "", and null. Return DataFrame with [table, column, ni_count, un_count, ot_count, empty_count, null_count, total_rows].

8. `completeness_heatmap_symbol(pct: float) -> str`:
   Map completeness percentage (0.0-1.0) to Unicode block character:
   ≥0.95→█, ≥0.75→▓, ≥0.50→▒, ≥0.25→░, >0→·, 0→○

9. `flag_small_cell(value: int) -> str`:
   If 1 ≤ value ≤ SMALL_CELL_THRESHOLD, return f"{value} ⚠". Otherwise return str(value).

All integrity functions must use `pl.scan_parquet()` (lazy) and `.collect()` only when needed. Do NOT use `pl.read_parquet()` (eager) for large tables.

**Main flow (`def main(config_path=None)`):**

1. Load config via `load_config()`. Print data_root, parquet_dir.
2. Parse table list via `parse_datastructure()`. Build a mapping from table_name → parquet_path: for each filename, extract table_name via `filename.split("_Mailhot_V1")[0]`, parquet file is `parquet_dir / (filename.stem + ".parquet")` — reuse the same stem logic from convert_all.py.
3. Create `reports/` directory under PROJECT_ROOT.
4. **DatasetCoverPage parsing:** Look for `DatasetCoverPage*.txt` in `data_root` using glob. If found, call `parse_cover_page()`. If not found or parsing returns empty dict, print warning and proceed without schema comparison (the report will note "DatasetCoverPage not available").
5. **Schema validation:** For each table, call `validate_table_schema()` passing `is_tumor_registry=(table_name in TUMOR_REGISTRY_TABLES)` and `expected_col_count=TUMOR_REGISTRY_EXPECTED_COUNTS.get(table_name)`. Collect results.
6. **PATID uniqueness:** Call `check_patid_uniqueness()` on DEMOGRAPHIC parquet.
7. **PATID integrity:** For each table in PATID_LINKED_TABLES, call `check_patid_integrity()`. Skip if parquet file doesn't exist. Collect results.
8. **ENCOUNTERID integrity:** For each table in ENCOUNTER_LINKED_TABLES, call `check_encounterid_integrity()`. Pass `skip_partner="CHP"` for LAB_RESULT_CM. Skip if parquet file doesn't exist. Collect results.
9. **Completeness:** For each table, call `completeness_by_partner()`. Concatenate all results into one DataFrame.
10. **Missing value classification:** For each table, call `classify_missing_values()`. Concatenate results.
11. **Write reports/completeness_by_partner.csv:** Write the concatenated completeness DataFrame to CSV.
