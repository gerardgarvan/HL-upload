2. `flag_duplicates(df: pl.DataFrame, table_name: str) -> pl.DataFrame` — Look up table_name in DEDUP_KEYS. Filter to available keys (present in df.columns). If fewer than 2 available keys, return df unchanged. Use `df.select(available_keys).is_duplicated()` to get a boolean mask marking ALL duplicate rows (both first and subsequent occurrences). Add as `IS_DUPLICATE` column cast to Int8. This uses DataFrame.is_duplicated() on a column subset — simpler than pl.struct. Do NOT cast key columns to String first; is_duplicated works on native types and handles nulls correctly (null != null, so rows with null keys are NOT flagged as duplicates of each other — this is correct behavior).

Return dict with keys: `multi_birth_date` (list of patient IDs with >1 distinct BIRTH_DATE), `multi_sex` (list of patient IDs with >1 distinct SEX), `total_patients` (unique ID count). Cast PATID_COL to String. If DEMOGRAPHIC not in table_map or file doesn't exist, return empty dict.

4. `flag_events_outside_encounters(event_df: pl.DataFrame, encounter_df: pl.DataFrame, event_date_col: str) -> pl.DataFrame` — If ENCOUNTERID not in event_df.columns, return unchanged. Cast ENCOUNTERID to String on both sides. Left-join event_df with encounter_df on ENCOUNTERID (select only ENCOUNTERID, ADMIT_DATE, DISCHARGE_DATE from encounter_df). Add `_con_outside_encounter` Int8 flag: 1 when event_date_col falls outside [ADMIT_DATE - 1 day, DISCHARGE_DATE + 1 day]. Use `pl.duration(days=1)` for date arithmetic. Handle nulls: if ENCOUNTERID is null OR ADMIT_DATE is null OR event_date_col is null → flag=0 (cannot assess). If DISCHARGE_DATE is null → treat as open-ended (only check >= ADMIT_DATE - 1d). Drop the joined ADMIT_DATE and DISCHARGE_DATE columns before returning. Use lazy evaluation (`.lazy()` / `.collect()`) for memory efficiency.

Since TR dates may be strings, parse using the Phase 4 fallback chain: `str.to_date("%m/%d/%Y", strict=False).fill_null(str.to_date("%d%b%Y", strict=False)).fill_null(str.to_date("%Y%m%d", strict=False))`. Join on PATID_COL (cast to String). Count patients where dates differ. Return dict with `patients_checked`, `patients_mismatched`, `details`. If DEATH table not available, return empty dict.

Create `src/clean/harmonize.py` with a module docstring. Import `polars as pl` and `from src.validate.structural import PATID_COL`.

**Constants:**

`PARTNER_FLAGS: dict[str, set[str]]` mapping flag names to partner identifiers:
- "ICD_MAPPED": {"AMS", "UMI"} — partners that retrospectively mapped ICD-9 to ICD-10
- "CLAIMS_ONLY": {"FLM"} — claims-only partner (no labs, vitals, prescribing)
- "DEATH_ONLY": {"VRT"} — death data only

**Functions:**

1. `add_partner_flags(df: pl.DataFrame, partner_col: str = "SOURCE") -> pl.DataFrame` — If partner_col not in df.columns, return unchanged. For each (flag_name, partners) in PARTNER_FLAGS: add Int8 column where 1 = partner_col value is in the partners set. Pass a Python set to `is_in()` (NOT a Polars Series — deprecated per Pitfall 5). Example: `pl.col(partner_col).is_in({"AMS", "UMI"}).cast(pl.Int8).alias("ICD_MAPPED")`.

2. `flag_encounters_outside_enrollment(encounter_df: pl.DataFrame, enrollment_df: pl.DataFrame) -> pl.DataFrame` — Check whether each encounter's ADMIT_DATE falls within at least one enrollment period. Steps:
   a. Select enrollment subset: ID (cast to String), ENR_START_DATE, ENR_END_DATE.
   b. Cast encounter ID to String.
   c. Use lazy evaluation: left-join encounter with enrollment on ID.
   d. Compute `_covered` per joined row: 1 if ENR_START_DATE and ENR_END_DATE are not null AND ADMIT_DATE is between them (inclusive), else 0. If ADMIT_DATE is null → _covered = 0 (cannot assess, don't flag).
   e. Group by ALL original encounter columns and aggregate max(_covered) as `_any_covered`.
   f. Final flag: `_con_outside_enrollment` Int8 = 1 when _any_covered == 0 AND ADMIT_DATE is not null (i.e., has a date but no enrollment covers it). When ADMIT_DATE is null, flag = 0.
   g. Drop `_any_covered` helper column.
   h. Return the encounter DataFrame with the new flag.
   Important: this join can produce a large intermediate result (many-to-many on ID). The lazy evaluation + group_by collapse keeps memory manageable. If ADMIT_DATE not in encounter_df.columns, return unchanged.

3. `flag_no_enrollment(encounter_df: pl.DataFrame, enrollment_df: pl.DataFrame) -> pl.DataFrame` — Flag patients who have encounters but zero enrollment records. Steps:
   a. Get unique IDs from enrollment (cast to String).
   b. Cast encounter ID to String.
   c. Anti-join encounter IDs against enrollment IDs.
   d. Add `_con_no_enrollment` Int8 flag: 1 for patients with no enrollment records at all.
   e. Use `pl.col(PATID_COL).is_in(no_enr_ids)` with a Python list (not Series).
   f. Return encounter DataFrame with the new flag.
