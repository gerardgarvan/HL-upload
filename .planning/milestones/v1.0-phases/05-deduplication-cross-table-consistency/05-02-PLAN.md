**main(config_path=None):**

Print banner: "HL DATA LOADING & CLEANING — DEDUPLICATION & HARMONIZATION"

Step 1 — Load config:
- `paths = load_config(config_path)`
- `_, table_filenames = parse_datastructure(paths.datastructure_path)`
- `table_map = _build_table_map(table_filenames, paths.parquet_dir)`
- `reports_dir = PROJECT_ROOT / "reports"` ; `reports_dir.mkdir(parents=True, exist_ok=True)`

Step 2 — Load reference tables:
- Load ENCOUNTER DataFrame (for event-window checks). Select ENCOUNTERID (cast to String), ADMIT_DATE, DISCHARGE_DATE. If ENCOUNTER not in table_map or doesn't exist, set encounter_ref = None.
- Load ENROLLMENT DataFrame (for insurance checks). Select ID (cast to String), ENR_START_DATE, ENR_END_DATE. If ENROLLMENT not in table_map or doesn't exist, set enrollment_ref = None.
- Print reference table row counts.

Step 3 — Main cleaning loop:
Iterate `sorted(table_map.items())` with progress counter `[idx/total]`.

For each (table_name, pq_path):
  a. Skip if parquet file doesn't exist (print SKIP).
  b. `df = pl.read_parquet(pq_path)`
  c. `df = drop_existing_clean_flags(df)` — idempotent re-run
  d. `initial_cols = len(df.columns)`
  e. `df = flag_duplicates(df, table_name)` — adds IS_DUPLICATE if table in DEDUP_KEYS
  f. `df = add_partner_flags(df)` — adds ICD_MAPPED/CLAIMS_ONLY/DEATH_ONLY if SOURCE column exists
  g. Event-encounter window check: if table_name in EVENT_DATE_COLS and encounter_ref is not None and "ENCOUNTERID" in df.columns:
     - `event_date_col = EVENT_DATE_COLS[table_name]`
     - if event_date_col in df.columns: `df = flag_events_outside_encounters(df, encounter_ref, event_date_col)`
  h. ENCOUNTER-specific: if table_name == "ENCOUNTER" and enrollment_ref is not None:
     - `df = flag_encounters_outside_enrollment(df, enrollment_ref)`
     - `df = flag_no_enrollment(df, enrollment_ref)`
  i. `stats = write_cleaned(df, pq_path)` — writes back to same file
  j. Count `rows_with_any_flag`: collect all Phase 5 flag columns (IS_DUPLICATE, _con_*, ICD_MAPPED, CLAIMS_ONLY, DEATH_ONLY), if any: filter where any flag == 1, count height. Add `rows_with_any_flag` to stats.
  k. If table has SOURCE column: compute per-partner dedup summary:
     `partner_dedup = df.group_by("SOURCE").agg(pl.len().alias("total"), pl.col("IS_DUPLICATE").sum().alias("dup_count"))` (only if IS_DUPLICATE in df.columns). Store in stats["partner_dedup"].
  l. `report_data[table_name] = stats`
  m. Print: table_name, new flags added, rows flagged.

Step 4 — Cross-table summary checks (no per-row flags):
- `demo_consistency = check_demographic_consistency(table_map)`
- `death_consistency = check_death_consistency(table_map)`
- Print summary counts.

Step 5 — Report generation (call functions defined in Task 2).

Step 6 — Console summary: tables processed, total flag columns, total flagged rows, elapsed time, report file paths.

**Report 1 — _generate_dedup_report(report_data, reports_dir):**

Section 2 — Per-Partner Duplicate Rates (for tables with partner_dedup in stats):
| Partner | Table | Total | Duplicates | Rate |
Iterate tables with partner_dedup data. Apply flag_small_cell(). Sort by table then partner.

Section 3 — Methodology note: explain composite keys used, that ALL occurrences are flagged (not just subsequent), and that null keys do not match (correct behavior).

**Report 2 — _generate_consistency_report(report_data, demo_consistency, death_consistency, reports_dir):**

Creates `reports/consistency_report.md` with:

Section 1 — Demographics Consistency:
- Patients with multiple BIRTH_DATE values: count (flag_small_cell). List patient IDs only if count ≤ SMALL_CELL_THRESHOLD (HIPAA — don't list large numbers of IDs).
- Patients with multiple SEX values: same pattern.
- "0 inconsistencies" if none found.

Section 2 — Events Outside Encounter Windows:
| Table | Total Rows | Outside Window | Rate |
For tables with _con_outside_encounter in flags. Apply flag_small_cell(). Note ±1 day tolerance. Note that null ENCOUNTERID rows are not assessed.

Section 3 — Death Date Consistency:
Summary from death_consistency dict. Patients checked vs mismatched.

Section 4 — Insurance Enrollment Coverage:
- ENCOUNTER rows outside enrollment: count from _con_outside_enrollment flag
- Patients with no enrollment: count from _con_no_enrollment flag
- Apply flag_small_cell() to both.

**Report 3 — _generate_partner_report(report_data, reports_dir):**

Creates `reports/partner_harmonization.md` with:

Section 1 — Partner Flag Summary:
| Flag | Partners | Tables Flagged | Total Rows Flagged |
For each flag in PARTNER_FLAGS: count across all tables. Apply flag_small_cell().

Section 2 — ICD_MAPPED Partners (AMS, UMI):
- Total records flagged across all tables
- Note: these partners retrospectively mapped ICD-9 → ICD-10, so pre-Oct-2015 ICD-10 codes are expected
- Cross-reference with Phase 4's ICD concordance if icd_concordance.csv exists

Section 3 — CLAIMS_ONLY Partner (FLM):
- Total records flagged
- List tables FLM contributes to vs tables it's absent from (based on non-zero counts)
- Note: no labs, vitals, or prescribing data available

Section 4 — DEATH_ONLY Partner (VRT):
- Total records flagged
- Note: contributes only death records

Each report has: title, generated timestamp, data source paths, table of contents.
